# スマホでWi-Fiとバックアップ先を設定する

カメラが出す設定用Wi-Fiにスマホをつないで、ブラウザから設定する。

## 最初の設定

1. SDを入れて電源ON。Wi-Fi未設定なら設定用Wi-Fiが出る
2. スマホで `Camera-XXXXXX` につなぐ（末尾は機器ごとに違う）
3. パスワードは `camera-setup`。「インターネットなし」と出てもそのままつないでおく
4. ブラウザで `http://192.168.4.1` を開く（自動では開かない）
5. 「Wi-Fiを検索」で接続先を選んでパスワードを入れる。手入力もできる
6. 「カメラ設定用Wi-Fiの新しいパスワード」を12〜63文字で決める。次に設定画面を開くときに使うので控えておく
7. バックアップ先を入れるなら入れて「設定を保存」
8. 接続できたか確認。SDに写真があれば「バックアップを試す」で1枚送って確かめられる
9. 「設定を終了」。スマホは普段のWi-Fiに戻す

設定用Wi-Fiは10分で止まる。パスワードを変えても、今出ている設定用Wi-Fiは止まるまで古いパスワードのまま。

設定用Wi-Fiが出ている間は自動バックアップは止まる（「バックアップを試す」は使える）。試している間は画面が重くなるけど撮影には影響しない。

## Wi-Fiを選び直す

撮影ボタンを押したまま電源を入れて、起動したら離す。設定用Wi-Fiが出るので同じように `192.168.4.1` を開く。このときの長押しでは撮影しない。

Wi-Fiは3件まで保存。最後に選んだものを優先して、だめなら他のを順に試す。「ほかの保存済みWi-Fiを忘れる」で今回の1件だけ残せる。

どのWi-Fiにもつながらない状態が1分くらい続くと設定用Wi-Fiが出る。タイムアウトで閉じたあとにまた開きたいときは、ボタンを押したまま再起動する。

2.4GHzのみ。スマホのテザリングを登録したいけど設定用Wi-Fiにつないでいる間テザリングを出せない機種なら、名前を手入力して、設定を終わってからテザリングをONにする。別のスマホやPCで設定してもいい。

## バックアップ先

HTTPSのWebDAVフォルダだけ対応。

| 保存先 | 対応 |
| --- | --- |
| WebDAVが使えるNAS・サーバー | OK（Basic認証 or 認証なしでPUT/GETできれば） |
| Nextcloud | OK。WebDAVのフォルダURL + ユーザー名 + アプリパスワード |
| Windowsの共有フォルダ (SMB) | 直接は無理。WebDAVを別に立てる |
| Google Drive / OneDrive / Dropbox | 未対応 |
| S3 / FTP / SFTP | 未対応 |

Nextcloudなら `https://cloud.example.com/remote.php/dav/files/USERNAME/Camera` のような形。`Camera` フォルダは先に作っておく。ユーザー名などに特殊文字があるときはNextcloudに表示されるWebDAVのURLを使う。参考: [Nextcloud WebDAV](https://github.com/nextcloud/documentation/blob/master/developer_manual/client_apis/WebDAV/basic.rst)

保存先は1か所だけ。変えると新しい方へ送り直す。自動バックアップをONにすると、SD直下にもともとある `.jpg` / `.JPG` も送る。SDの写真は消さない。

証明書はちゃんと検証する。普通の認証局なら内蔵の証明書で通る。自己署名やオレオレCAのNASなら「証明書・時刻の設定」にCA証明書（PEM）を貼る。検証を切る設定やHTTPでの送信はない。

証明書の期限を見るために、時刻を合わせてから送信を始める。NTPは `pool.ntp.org`。外に出られないネットワークならそこのNTPサーバーを入れる。

## 送信の流れ

1. SDに保存して読み戻しで確認
2. 写真をPSRAMに読む（2MBまで、16KBずつSDのロックを外しながら）
3. 中身のSHA-256をファイル名にしてPUT。同じ写真は何度送っても同じ名前
4. GETで読み戻してバイト単位で比較
5. 一致したらSDの `/.backup/` に送信済みの記録を作る

失敗したら5秒〜最大60秒の間隔でリトライ。レスポンスが返ってこなかったときは同じ写真をもう一度送ることがある。再起動してもSDの記録を見て続きから。

送信済みの記録は「送ったときに一致した」というだけで、あとで向こうで消されたかは見ていない。記録を消すとまた確認して送り直す。

読めない・空・2MB超えの写真は飛ばして次へ。認証やHTTPのエラーならその写真をリトライ。どちらでもSDの写真は消さない。

## 設定の保存場所など

Wi-Fiと保存先の設定はNVS。設定画面は設定用Wi-Fi側からしか開けない。保存したパスワードは画面にもAPIにも返さない。変更にはセッションごとのトークンが必要。

NVSの暗号化はしていない。人に渡すときは設定をやり直して、SDの写真にも気をつける。設定用Wi-Fiのパスワードを忘れたときのリセット方法はまだない。

## 確認状況

PCのテスト（偽のWi-Fi・HTTP・SD）で、保存、パスワードを返さないこと、アクセス制限、再接続、レスポンスなし、不一致、再送を確認した。設定画面はChromiumでPC幅とスマホ幅を確認。

実機のWi-Fi、NAS・Nextcloudへの送信はまだ試していない。最初はテスト用の写真で、設定・送信・電源の入れ直しまで確認する。
